# 말차 (Malcha)

가상의 인물과 롤플레이 대화를 하며 외국어를 배우는 개인용 학습 앱.

- HTML 파일 하나로 동작하며, 대화·단어장·캐릭터·API 키는 모두 **각 기기의 브라우저 안에만** 저장됩니다. 이 저장소에는 개인 데이터가 없습니다.
- 모델 연결: ⚙ 설정에서 로컬(Ollama) 또는 온라인 API(OpenAI 호환, 여러 프로필 저장 가능)를 선택합니다. 교정·단어·힌트 같은 보조 작업은 따로 가벼운 모델에 맡길 수 있어요.
- 기기 간 이동이나 백업은 앱의 **⬇ 대화 내보내기 / ⬆ 불러오기**를 사용하세요.
