설정

여러 서비스를 등록해 두고 골라 쓸 수 있어요. 아래 주소·키·모델은 선택한 프로필에 저장되고, 저장을 누르면 선택한 프로필로 대화합니다.
예시 — OpenRouter: https://openrouter.ai/api/v1 · Groq: https://api.groq.com/openai/v1 · Gemini: https://generativelanguage.googleapis.com/v1beta/openai · OpenAI: https://api.openai.com/v1
키는 이 브라우저에만 저장되며 대화 백업 파일에는 절대 포함되지 않습니다. 이 앱 전용 키를 새로 만들고, 서비스 대시보드에서 지출 한도를 걸어두는 것을 권장해요.
qwen3 같은 생각 모드 모델이 답하기 전에 보이지 않는 "생각"을 길게 하지 않게 해요. 대화 품질은 거의 같고 훨씬 빨라져요.
답장은 위의 대화 모델이 쓰고, 나머지 작업만 여기서 고른 모델이 맡아요. 예: 답장은 gemini-2.5-flash, 교정은 더 가볍고 무료 한도가 넉넉한 gemini-2.5-flash-lite. 보조 모델이 실패하면 대화 모델로 다시 시도해요.
자동 교정·단어 수집·미션 자동 판정을 끄고 답장만 받아요. 느린 컴퓨터에서 로컬 모델을 쓸 때 추천해요. 교정은 내 메시지 아래 📝 교정받기 버튼으로 필요할 때만 받을 수 있어요.
확인 중…
대화·캐릭터·단어장·로어북·리포트를 내 구글 드라이브의 숨김 앱 폴더에 저장해서 폰과 노트북을 맞춰요. 나만 볼 수 있고, API 키와 설정은 기기마다 따로예요.
고급: 구글 클라이언트 ID
캐릭터가 이야기 속에서 사진을 보내면 📷 사진 보기로 실제 사진을 찾아 보여줘요. pexels.com/api에서 가입하면 키를 무료로 바로 받을 수 있어요 (시간당 200장). 키는 이 브라우저에만 저장돼요.
대화가 그만큼 쌓이면 "여기까지 학습한 내용을 정리하겠습니까?"라고 물어봐요. 정리하면 지난 리포트 이후 구간만 리포트로 만들어요.
복습할 때가 된 단어 1~2개를 상대가 대화 중에 자연스럽게 써 줘요. 억지로 넣지는 않아요.
운영체제에 내장된 음성을 사용해서 오프라인에서도 동작해요. 각 메시지의 🔊 버튼으로 개별 재생도 됩니다.
처음이라면 (인터넷 없이 동작하는 로컬 모델)
1. ollama.com에서 Ollama 설치 후 모델 받기 — 예: ollama pull qwen3:8b (사양이 낮은 노트북이면 qwen3:1.7b)
2. 브라우저에서 접근을 허용한 상태로 실행 (웹 주소로 쓰는 중이면 * 대신 https://cs0710.github.io도 돼요):
  · macOS/Linux: OLLAMA_ORIGINS="*" ollama serve
  · Windows(PowerShell): $env:OLLAMA_ORIGINS="*"; ollama serve
3. 위의 연결 테스트 → 모델 선택 → 저장

📱 핸드폰에서 쓰기 (PC와 같은 와이파이)
1. PC에서 모델을 외부 접속 허용으로 실행:
  · macOS/Linux: OLLAMA_HOST=0.0.0.0 OLLAMA_ORIGINS="*" ollama serve
  · Windows(PowerShell): $env:OLLAMA_HOST="0.0.0.0"; $env:OLLAMA_ORIGINS="*"; ollama serve
2. malcha.html이 있는 폴더에서 간이 서버 실행: python3 -m http.server 8420
3. 폰 브라우저에서 http://PC의IP:8420/malcha.html 접속 (PC IP는 ipconfig/ifconfig로 확인)
4. 위의 Ollama 주소를 http://PC의IP:11434로 바꾸고 연결 테스트 → 브라우저 메뉴에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요
